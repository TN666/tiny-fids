# tiny-fids

**English** | [中文](#中文)

![](enclosure/makerworld/images/IMG_1279.JPG)

An airport-style flight information display (FIDS) for the **LilyGO T-Display S3 Touch** (320×170). It shows live departures and arrivals for **Taipei Taoyuan (TPE)** and **Taipei Songshan (TSA)**. The UI mimics a real airport board: amber header, navy rows, alternating Chinese/English text, codeshare cycling and a flip animation. It comes with a 3D-printable inverted-T desk stand.

## Data sources (official open data, no API key)
| Airport | URL | Format |
|---|---|---|
| Taoyuan | `taoyuan-airport.com/uploads/flightx/a_flight_v4.txt` | Big5 CSV (both terminals, departures and arrivals) |
| Songshan | `tsa.gov.tw/api/publicDataArea/GetFormaterData?id=…` (4 feeds) | JSON (international/domestic × departures/arrivals) |

Data refreshes every 3 minutes. Downloads run in a background task on core 0, so the UI never freezes.

## Controls
| Input | Action |
|---|---|
| **BOOT** (GPIO0) short press | Switch airport TPE ⇄ TSA |
| **BOOT** long press | Brightness (4 levels) |
| **KEY** (GPIO14) short press | Next page |
| **KEY** long press | Switch departures ⇄ arrivals |
| Swipe up / down | Change page |
| Swipe left / right | Switch airport |
| Tap the header | Switch departures ⇄ arrivals |
| Tap a flight | Details (gate, counter, baggage belt, aircraft, codeshares); tap again or press any button to go back |
| Long-press the screen | Refresh now |

The board auto-pages every 8 seconds through the first 5 pages. Auto-paging pauses for 30 seconds after any manual input. The dot next to the clock shows status: green = OK, blinking blue = updating, red = update failed or data is stale. The airport, direction and brightness are remembered across reboots.

## Flashing
```bash
pio run -t upload        # or use PlatformIO in VS Code
pio device monitor
```
On first boot the device opens a Wi-Fi setup hotspot named **FIDS-Setup**. Connect to it with your phone and pick your home Wi-Fi on the web page that opens. You can also hard-code `WIFI_SSID` / `WIFI_PASS` in `src/config.h`.

If the screen is upside down, set `SCREEN_ROTATION` in `src/config.h` to `1`.

## Preview the UI on your computer
`sim/build.sh` downloads live data and renders screenshots on macOS/Linux, using the same UI and parser code as the firmware. It needs SDL2 (`brew install sdl2`).
```bash
sim/build.sh                       # screenshots go to sim/out/
sim/build.sh sim/out 1792571400    # simulate a given time (epoch; here 2026-10-21 16:30)
```

## Files
- `src/main.cpp`: buttons, touch gestures, Wi-Fi, main loop
- `src/ui.cpp`: board and detail-page rendering
- `src/parser.cpp`: Taoyuan CSV (Big5) and Songshan JSON parsing, codeshare merging
- `src/fetcher.cpp`: HTTPS download and background refresh
- `src/lgfx_tdisplay_s3.h`: display and touch pin setup
- `tools/gen_big5.py`: generates the Big5→Unicode table `src/big5_table.h`

## 3D-printed enclosure
An inverted-T airport-board stand made of four parts: front shell, snap-fit back cover, display panel and base. It needs no screws and no supports.
The STLs are in [`enclosure/makerworld/stl/`](enclosure/makerworld/stl/). Design notes and assembly steps are in [`enclosure/README.md`](enclosure/README.md).
The enclosure is generated by Fusion 360 API scripts (`enclosure/build_enclosure.py`, `enclosure/build_block.py`). Board dimensions come from LilyGO's official 3D model.

## 中文

[English](#tiny-fids) | **中文**

在 LilyGO **T-Display S3 Touch**（320×170）上顯示**桃園機場（TPE）**與**松山機場（TSA）**的即時出發／抵達航班。介面仿照機場大螢幕：琥珀色標題列、深藍底、中英文交替顯示、共用班號輪播、翻頁動畫。另附可 3D 列印的倒 T 字形桌上看板外殼。

### 資料來源（官方開放資料，不需要 API 金鑰）
| 機場 | 網址 | 格式 |
|---|---|---|
| 桃園 | `taoyuan-airport.com/uploads/flightx/a_flight_v4.txt` | Big5 CSV（兩航廈、出發＋抵達） |
| 松山 | `tsa.gov.tw/api/publicDataArea/GetFormaterData?id=…`（4 個） | JSON（國際/國內 × 出發/抵達） |

每 3 分鐘更新一次。資料在背景工作（core 0）下載，畫面不會卡住。

### 操作
| 操作 | 功能 |
|---|---|
| **BOOT 鍵**（GPIO0）短按 | 切換機場 桃園 ⇄ 松山 |
| **BOOT 鍵** 長按 | 調整亮度（4 段） |
| **KEY 鍵**（GPIO14）短按 | 下一頁 |
| **KEY 鍵** 長按 | 切換 出發 ⇄ 抵達 |
| 觸控 上／下滑 | 翻頁 |
| 觸控 左／右滑 | 切換機場 |
| 點標題列 | 切換 出發 ⇄ 抵達 |
| 點一班航班 | 詳細資訊（登機門、櫃台、轉盤、機型、共用班號），再點一下或按任一鍵返回 |
| 長按螢幕 | 立即更新資料 |

看板每 8 秒自動翻頁，輪播前 5 頁；手動操作後會暫停 30 秒。標題列時鐘旁的燈號：綠＝正常、藍閃＝更新中、紅＝更新失敗或資料過舊。機場、方向、亮度會記住，重開機後保留。

### 燒錄
```bash
pio run -t upload        # 或用 VS Code 的 PlatformIO
pio device monitor
```
第一次開機會開啟 Wi-Fi 設定熱點 **FIDS-Setup**，用手機連上後，在網頁中選擇家裡的 Wi-Fi。也可以直接在 `src/config.h` 填入 `WIFI_SSID` / `WIFI_PASS`。

畫面上下顛倒的話，把 `src/config.h` 的 `SCREEN_ROTATION` 改成 `1`。

### 在電腦上預覽介面
`sim/build.sh` 會下載最新資料，用和韌體同一份 UI 與解析程式碼，在 Mac/Linux 上渲染出截圖。需要 SDL2（`brew install sdl2`）。
```bash
sim/build.sh                       # 截圖輸出到 sim/out/
sim/build.sh sim/out 1792571400    # 指定模擬時間（epoch，此例為 2026-10-21 16:30）
```

### 檔案
- `src/main.cpp`：按鍵、觸控手勢、Wi-Fi、主迴圈
- `src/ui.cpp`：看板與詳細頁繪製
- `src/parser.cpp`：桃園 CSV（Big5）與松山 JSON 解析、共用班號合併

- `src/lgfx_tdisplay_s3.h`：螢幕／觸控腳位設定

### 3D 列印外殼
倒 T 字形的機場看板外殼，分成四個零件：前框、卡扣背蓋、看板面板、底座。免螺絲、免支撐。
STL 在 [`enclosure/makerworld/stl/`](enclosure/makerworld/stl/)，設計說明與組裝方式見 [`enclosure/README.md`](enclosure/README.md)。
外殼由 Fusion 360 API 腳本產生（`enclosure/build_enclosure.py`、`enclosure/build_block.py`），板子尺寸參考 LilyGO 官方 3D 模型。
